Folder structure for Organotchi
Please organize the organoid images using the following folder structure:
raw_data/
    Day <day_number>/
        <batch_or_condition_name>/
            Tile000001.jpg
            Tile000002.jpg
            Tile000003.jpg
            ...
For example:
raw_data/
    Day 0/
        Control/
            Tile000001.jpg
            Tile000002.jpg
            Tile000003.jpg
            ...
        Treatment/
            Tile000001.jpg
            Tile000002.jpg
            Tile000003.jpg
            ...
    Day 5/
        Control/
            Tile000001.jpg
            Tile000002.jpg
            Tile000003.jpg
            ...
        Treatment/
            Tile000001.jpg
            Tile000002.jpg
            Tile000003.jpg
            ...
Important notes
The batch or condition names can be chosen by you, but please keep them consistent across time points. For example, if you use Control and Treatment at Day 0, please use the same names at later time points.
The organoid images can be provided in either .jpg or .tif format.
